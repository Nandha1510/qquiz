📄 Project Description:
The React Quiz App is a dynamic and interactive web application built using ReactJS and Vite. It presents users with a series of multiple-choice questions from various topics and provides immediate feedback upon completion.

The app includes the following features:

12 to 15 carefully curated multiple-choice questions

Real-time scoring and result display

Highlights correct answers for wrongly chosen options

Sleek, user-friendly UI with responsive design

Built-in score calculation logic

Simple restart/retake functionality

This project was created as part of a front-end development internship and demonstrates proficiency in React hooks (useState, useEffect), component-based architecture, and modern styling.

🛠 Tech Stack Used:
ReactJS (Vite)

JavaScript

CSS (or Tailwind/SCSS if applicable)

HTML

✅ Key Learning Outcomes:
Hands-on experience with React state and component management

Dynamic rendering of components and conditional logic

Project structuring and file organization

Using .gitignore for cleaner version control

Basic debugging and testing during development
